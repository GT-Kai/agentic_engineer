## 每周怎么用

每周日固定 30 分钟：

1. 在 [roadmap.md](roadmap.md) 里把完成的验收项勾掉
2. 在 [log.md](log.md) 顶部追加一条周记录（模板在文件内）
3. 更新本页的进度总览
4. 给下周定**不超过 3 个**目标

## 约定

- 日期统一 `YYYY-MM-DD`，周次 `2026-W45`
- 论文编号 `P-01`，实验编号 `EXP-001`，项目编号 `P1/P2/P3`
- 验收项写成 `- [ ]`，完成后改成 `- [x]`
- 所有结论必须带数字，禁止"效果不错""明显提升"
- 实验记录必须包含：目标、配置、结果、结论、下一步

## 三条原则

1. **产物驱动**：每个阶段结束必须有能跑的东西，不接受"看完了"。
2. **先闭环再 scale**：先在小模型、小数据上跑通全链路，再谈规模。
3. **写作即理解**：讲不清楚，就是没学会。每个阶段一篇复盘。
